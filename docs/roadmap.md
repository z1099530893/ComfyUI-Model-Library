# 开发计划

本文记录项目的最终目标、已经完成的阶段、当前状态和后续计划。

最后更新：2026-11-19

---

## 1. 最终目标

把本地模型的日常使用串成一条闭环：

```
发现模型 → 下载 → 自动归档 → 浏览与检索 → 拖进 ComfyUI 工作流
```

具体目标：

1. **下载即整理**：下载完成后自动按类型归档，补齐说明、示例图和元数据，不需要手工建文件夹、改名、写触发词。
2. **一个模型库，两处可用**：下载器和 ComfyUI 插件读取同一批模型和同一份 `model.json`，数量、名称、基础模型分类保持一致。
3. **在 ComfyUI 里直接找模型**：侧边栏浏览、搜索、看示例图，拖到画布就能用，不用记文件名。
4. **安全**：插件只读；下载器删除只进回收站；任何操作都不破坏已有模型。
5. **可持续维护**：代码、文档、备份和版本管理齐全，后续可以继续加站点、做安装包。

---

## 2. 产品原则

- **本地优先**：模型和元数据都在本机，不依赖云端账号。
- **渐进式**：先打通一条可用链路，再补站点和打包，不一次性堆功能。
- **约定优于配置**：目录结构和 `model.json` 固定，两个工具共享。
- **只读优先**：浏览类功能绝不修改模型文件；删除必须明确确认。
- **中文优先**：界面、文档、注释都是中文，面向非技术用户。

## 8. 完成标准

当以下条件都满足时，可以认为第一阶段目标完成：

- 下载器能稳定完成 Civitai 下载、归档、说明生成，且模型库可正常浏览和管理；
- 插件能在 ComfyUI 中稳定浏览同一批模型，6 类模型拖拽插入正确；
- 两边显示的数量差异有明确解释；
- 安装步骤能让新用户从零跑起来；
- 代码有备份、有版本记录、有回滚方法；
- 删除、NSFW、拖拽等高风险操作经过实际验证。
