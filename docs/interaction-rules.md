# 人机协作规则

本文记录这个项目里「人」和「AI 开发搭档」如何配合，目的是让需求推进稳定、改动可控、出问题能回滚。

---

## 1. 角色

- **你（产品负责人 / 验收人）**：提出目标、提供截图和现象、决定优先级、做最终验收。
- **AI（开发搭档）**：读代码、给方案、写实现、做测试、整理文档、说明风险。

默认使用中文沟通，代码注释和界面文案也使用中文。

---

## 2. 基本原则

### 2.1 先讨论，后动手

涉及以下内容时，先给方案并等确认，不直接改代码：

- 新功能、新架构、目录结构调整；
- 会影响现有行为或数据格式的改动；
- 需要引入依赖、修改 ComfyUI 核心文件、改动系统配置。

小的文案、样式、明显 bug 可以直接修，但要在交付时说明。

### 2.2 备份优先

- 下载器每个里程碑、每次批量改动前，用 `tools/snapshot.ps1` 打快照。
- 插件从发布起纳入 Git 版本管理；大改前先提交或打标签。
- 备份只针对代码，不备份模型文件。

详见 [代码备份逻辑与备份节点](backup.md)。

### 2.3 模型文件只读

- 插件永远不移动、不改名、不删除模型文件。
- 下载器只有在用户明确点击删除并确认后，才把「模型文件 + 同名资料夹」移入回收站，不做永久删除。
- 调试、扫描、生成缩略图都不能修改模型目录里的文件。

### 2.4 只做被要求的事

- 不顺手重构、不扩大范围、不提前实现「以后可能用得上」的功能。
- 不新增多余文档、依赖或配置项。
- 发现相邻问题时先说明，由你决定是否处理。

---

## 3. 需求流程

1. **描述现象**：一句话说明目标，配截图或报错信息。
2. **AI 复述与定位**：先确认理解，再读相关代码/配置，给出原因。
3. **给方案**：说明改哪里、影响什么、怎么验证；有多种做法时列选项和取舍。
4. **实现**：尽量小步修改，保持现有风格。
5. **自测**：按第 4 节验证，记录结果。
6. **交付**：说明改了什么、需要重启还是刷新、如何回滚。

需求有变化时，以最新一条消息为准；已经确认暂停的项目不再改动。

---

## 4. 验证规则

### 4.1 下载器

- 修改后端逻辑后，用下载器自己的 Python 环境跑最小验证（导入模块、调用扫描/归档函数）。
- 涉及界面时，实际启动下载器看效果，避免只改 CSS 不验证。
- 操作模型文件的测试使用临时目录，不拿真实模型做删除/移动实验。

### 4.2 ComfyUI 插件

- 后端改动必须**重启 ComfyUI**才生效；前端改动刷新页面（`Ctrl+F5`）即可。
- 测试时另起一个实例（例如 `--port 8189`），不要占用或杀掉你正在使用的 `8188`。
- 优先用接口验证数据（列表、详情、缩略图），再用浏览器验证交互（侧边栏、搜索、详情、拖拽、NSFW）。
- 拖拽类改动必须实际拖一次，确认节点类型和参数值正确。
- 测试结束关闭临时实例。

### 4.3 验收标准

- 你描述的现象消失，且没有引入新的控制台报错。
- 原有功能（搜索、筛选、插入、打开文件夹等）仍然正常。
- 模型文件数量和修改时间没有变化（只读功能）。

---

## 5. 交付格式

每次交付至少说明：

1. **改了什么**：按功能点列，不贴大段代码。
2. **生效方式**：重启 ComfyUI / 刷新页面 / 重新安装依赖。
3. **验证结果**：测了什么、结果如何。
4. **回滚方式**：用哪个快照或 Git 提交恢复。

示例：

> 已修复详情遮罩层挡住面板的问题，只改了 CSS。  
> 已在你正在运行的 8188 上强刷验证：搜索、筛选、详情正常，遮罩默认隐藏。  
> 你只需要按一次 `Ctrl+F5`，不用重启。

---

## 6. 边界与禁区

- 不修改 ComfyUI 自带文件（`main.py`、`nodes.py`、前端静态资源等），只通过 `custom_nodes` 扩展。
- 不修改下载器之外的无关项目；下载器暂停开发期间不主动加功能。
- 不读取、不上传用户模型文件内容；不上传 Token、代理账号等敏感信息。
- 不执行不可逆操作（永久删除、格式化、批量改名）。
- 不在未确认的情况下替换技术栈或目录结构。

---

## 7. 本项目中的实际做法

- 插件从设计到实现：先勘察 ComfyUI 版本、目录、`folder_paths`、内置模型库的拖拽映射，再确认方案，最后写代码。
- 交互问题通过截图反馈：例如面板一闪而过、NSFW 只能单向显示、拖拽类型不符，都是按「截图 → 定位 → 小改 → 实测」处理。
- 每次改完都说明是否需要重启，并用独立端口验证，不打断正在使用的 ComfyUI。
- 下载器与插件共享 `model.json` 约定，避免两边各维护一套元数据。
